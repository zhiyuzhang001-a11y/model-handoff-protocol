# Model handoff control

- Mode: `active`
- Changed: `installation default`
- Reason: `protocol installed`

`active` enables the model-handoff contract. `paused` keeps every protocol file
installed but suspends handoff enforcement until the user explicitly resumes it.

- Pause: `退出模型交接协议，保留文件。`
- Resume: `恢复模型交接协议。`
